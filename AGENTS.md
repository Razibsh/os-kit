# OS Kit

This repository is a kit that builds a personal AI operating system with the user.

- If the user asks to set up, build or start their OS: read `skills/build/SKILL.md` and follow it from Phase 0.
- The kit's reference files are in `skills/build/references/`. Read the ones SKILL.md names.
- Do not run the setup unless the user asked for it. If they only want to read or change the kit itself, help with that instead.
